# TDD Rule

> **⚠️ 이 규칙은 Rigid — 상황에 맞게 변형하지 마라.**
> 단계를 건너뛰거나, 순서를 바꾸거나, "이번만 예외"를 만들지 않는다.

## 0. 우선순위 (프로젝트별 규칙 우선)

- 프로젝트의 `CLAUDE.md` / `AGENTS.md`에 TDD 규칙이 있으면 **그 규칙이 우선**한다.
- 이 파일은 **기본값(fallback)** 이다. 프로젝트 규칙이 침묵하는 부분에만 적용한다.
- 충돌 시 프로젝트 규칙을 따르고, 이 파일의 해당 조항은 무시한다.

## 1. 적용 기준

### TDD 필수

- **비즈니스 로직** (계산, 검증, 상태 전이, 정규화)
- **API** (핸들러, 요청/응답 처리, 에러 경로, 폴백)
- **유틸 함수** (파싱, 변환, 포맷팅)
- **버그 수정** (재현 테스트를 먼저 작성 → 실패 확인 → 수정)

### TDD 불필요

- **타입 정의** (`type`, `interface` 선언만 있는 파일)
- **설정 파일** (`vite.config.ts`, `tsconfig.json`, `eslint` 설정 등)
- **순수 UI** (로직 없는 마크업/스타일/레이아웃)
- **SQL** (스키마, 마이그레이션, 쿼리 정의)

경계가 모호하면 **로직이 한 줄이라도 있으면 TDD 대상**으로 간주한다.

## 2. RED → GREEN → REFACTOR

### RED — 실패하는 테스트 작성

1. **하나의 동작 = 하나의 테스트.** 한 테스트에 여러 동작을 섞지 않는다.
2. 테스트를 **반드시 실행**해서 실패를 눈으로 확인한다. 실행 없이 넘어가지 않는다.
3. 실패 이유는 **"기능 미구현"** 이어야 한다. 오타, import 오류, 문법 오류, 환경 문제로 인한 실패는 RED가 아니다 — 고치고 다시 실행한다.
4. 처음부터 통과하는 테스트는 아무것도 증명하지 못한다. 테스트를 고친다.

### GREEN — 최소한의 코드

1. 테스트를 통과시키는 **최소한의 코드만** 작성한다.
2. **YAGNI.** 지금 테스트가 요구하지 않는 분기, 옵션, 추상화는 쓰지 않는다.
3. **신규 + 기존 테스트 전체**를 실행해 모두 통과하는지 확인한다.
4. 다른 테스트가 깨지면 GREEN이 아니다. 먼저 복구한다.

### REFACTOR — 정리

1. 중복 제거, 이름 개선, 헬퍼 추출만 한다.
2. 리팩터 중 **항상 green 유지.** 변경마다 테스트를 실행한다.
3. **새 동작 추가 금지.** 새 동작은 다음 RED에서 시작한다.

### 반복

다음 동작에 대한 **RED로 돌아간다.** 모든 요구 동작이 끝날 때까지 사이클을 계속한다.

## 3. 삭제 강제 규칙

- 테스트보다 **프로덕션 코드를 먼저 작성했다면 삭제하고 RED부터 재시작**한다.
- **"참고용"으로 남기는 것도 금지.** 주석 처리, 별도 파일 보관, 복붙 대기 모두 포함한다.
- 삭제한 코드를 보고 다시 쓰는 것도 허용되지 않는다. 테스트가 이끄는 설계로 새로 작성한다.

## 4. 변명 차단표

| 변명 | 반론 |
|------|------|
| "너무 단순해서 테스트 불필요" | 단순한 코드는 테스트도 30초면 끝난다. 단순한 코드가 가장 자주 조용히 깨진다. 테스트는 현재 동작을 고정하는 계약이다. |
| "나중에 테스트 추가하겠다" | 나중에 쓴 테스트는 구현을 따라 쓰게 되어 버그까지 통과시킨다. "나중"은 오지 않는다. |
| "시간이 없다" | 디버깅과 회귀 수정이 더 오래 걸린다. 테스트 없는 속도는 빌린 시간이다. |
| "삭제하면 낭비" | 매몰 비용 오류다. 검증 안 된 코드를 유지하는 비용이 다시 쓰는 비용보다 크다. |
| "프로토타입이다" | 프로토타입은 프로덕션이 된다. 버릴 코드라면 테스트도 버리면 된다 — 하지만 로직이 있으면 먼저 쓴다. |

## 5. 완료 체크

- [ ] 모든 새 동작에 대해 RED(실패 확인)를 거쳤다
- [ ] 실패 이유가 "기능 미구현"이었다
- [ ] 최소 코드로 GREEN을 만들었고 전체 테스트가 통과한다
- [ ] REFACTOR 후에도 green이다
- [ ] 테스트 전에 쓴 프로덕션 코드가 남아 있지 않다
